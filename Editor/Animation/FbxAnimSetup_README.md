# FBX 애니메이션 설정 도구

`Tools/YAMO/Animation/Mocap to Biped FBX Pipeline` 창(단축키 `8`)의
**FBX 애니메이션 설정** 탭입니다. 예전의 독립 창(단축키 `9`)은 이 탭으로 통합되어
더 이상 별도 메뉴가 없습니다. 탭은 세 부분으로 구성됩니다.

---

## 1 · 대상 FBX 목록 / 2 · 설정 적용 (클립 일괄 설정)

대상 FBX 목록에 올린 파일들의 **Import Settings**에 다음을 일괄 적용합니다.

- **Anim. Compression → Off**
- **클립 이름 → 파일명과 동일하게** (단일 클립 FBX 한정, 다중 클립은 기존 이름 유지)
- **Root Transform Rotation** : Bake Into Pose ✓ / Based Upon = Original
- **Root Transform Position (Y)** : Bake Into Pose ✓ / Based Upon = Original
- **Root Transform Position (XZ)** : Bake Into Pose ✓ / Based Upon = Original

### 사용법
1. Project 창에서 FBX를 선택하고 **선택 추가**, **폴더 추가**, 또는 드롭 영역에 드래그해 목록에 넣습니다.
   (폴더는 하위 폴더까지 재귀적으로 추가합니다.)
2. **설정 적용**을 누릅니다.

---

## 3 · 모션 바인딩만 실행

옵티트랙 등 모션캡처로 추출한 애니메이션 FBX는 기본 바인드 포즈가 정확한 T‑포즈가
아니어서 휴머노이드 리타게팅이 부정확합니다. 이 도구는 3ds Max/Blender 왕복 없이
Unity 안에서 정확한 T‑포즈 아바타를 만들어 바인딩합니다. Forearm Hinge 보정과
Max FBX 출력이 필요하면 OptiTrack/MMRP 파이프라인 탭을 대신 사용하세요.

**소스 형식**을 먼저 고릅니다.

| 형식 | 본 이름 예 | 출력 이름 |
|---|---|---|
| `OptiTrack` | `001_Hips`, `001_Spine1` (액터 접두사) | FBX 테이크 이름 (`_FBX` 접미사 제거) |
| `MMRP` | `Hips`, `LeftUpperArm`, `LeftHandIndex1` (Unity 표준 이름) | 파일 이름 (테이크는 항상 `Take 001`) |

형식이 맞지 않는 파일은 리네임이나 복사 전에 거부되고, 어느 탭/형식을 써야 하는지 상태 메시지에 표시됩니다.

리스트에 올린 각 모션 FBX에 대해 다음을 자동 처리합니다.

1. **파일명을 애니메이션 이름으로 변경** — OptiTrack은 테이크 이름(고정 접미사 `_FBX` 제거, 예: `드립_003`), MMRP는 파일 이름 그대로
2. **`_T` 접미사 복사본 생성** (예: `드립_003_T`)
3. 복사본의 **Import Animation 해제** → 프레임0 회전이 구워지지 않은 **순수 T‑포즈**로 임포트
4. 복사본 **Rig = Humanoid / Create From This Model**
5. **본 매핑**
   - OptiTrack: `{접두사}_…` 규칙으로 매핑하고 자동 매핑이 한 칸 밀리는 스파인은 강제 지정
     (`Spine → {접두사}_Spine`, `Chest → {접두사}_Spine1`; 접두사는 `_Hips` 본에서 자동 탐지)
   - MMRP: Unity 표준 본 이름을 그대로 매핑 (`Little`/`Pinky` 손가락 이름 모두 허용), `MMRP_*` 헬퍼 노드는 매핑하지 않음
6. **Left Eye / Right Eye / Jaw / UpperChest 매핑 제거** — 두 형식 공통, Neck·Head만 유지
7. 복사본의 **Avatar를 모션 파일 Avatar로 등록** (Copy From Other Avatar)
8. 모션 파일에 **1·2의 클립 설정**(압축 Off · 클립명 · Root Bake)까지 적용

### 사용법
1. **소스 형식**을 선택합니다.
2. Project 창에서 모캡 FBX를 선택하고 **선택 추가**, **폴더 추가**, 또는 드래그합니다.
   (폴더 추가는 이 도구가 만든 `_T`, `_Backup` 파일을 자동으로 제외합니다.)
3. **바인딩 실행**을 누릅니다.

### 이름 충돌 처리 (액터별 분리 파일, OptiTrack)

OptiTrack의 결과 파일명은 **파일 이름이 아니라 FBX 내부의 클립(테이크) 이름**에서 나옵니다.
그래서 같은 테이크를 액터별로 뽑은 파일들(`001.fbx`, `002.fbx` …)은 클립 이름이
모두 같아 하나의 목표 파일명을 두고 충돌합니다.

이 경우 도구는 **원본 파일명(액터 번호)을 뒤에 붙여 모두 살립니다.**

| 원본 | 클립(테이크) 이름 | 결과 |
|---|---|---|
| `001.fbx` | `드립_003_FBX` | `드립_003_001.fbx` + `드립_003_001_T.fbx` |
| `002.fbx` | `드립_003_FBX` | `드립_003_002.fbx` + `드립_003_002_T.fbx` |
| `003.fbx` | `솔로_007_FBX` | `솔로_007.fbx` + `솔로_007_T.fbx` (충돌 없음 → 그대로) |

- 충돌해서 이름이 바뀐 항목은 실행 후 상태 메시지에 그대로 표시됩니다.
- 이미 처리된 파일에 다시 실행해도 이름이 또 늘어나지 않습니다(멱등).
- 목록 밖의 기존 에셋과 이름이 겹치면 `_2`, `_3` … 을 붙이며, **어떤 경우에도 기존
  파일을 말없이 지우지 않습니다.**

### 주의사항
- 생성된 **`_T` 파일은 삭제하지 마세요.** 모션 파일이 이 파일의 Avatar를 참조합니다.
  (`_T` 파일 자체를 목록에 올리면 바인딩하지 않고 거부합니다.)
- 파이프라인 특성상 파일당 리임포트가 2회 일어나므로 대량 처리 시 시간이 걸릴 수 있습니다.
- 액터는 파일당 1명이라고 가정합니다. OptiTrack은 스파인 본 구성(Spine, Spine1~4)이 고정이라고 가정합니다.
- MMRP 파일은 스킨 메시가 포함되어 크기가 큽니다(수십 MB). `_T` 복사본도 같은 크기입니다.
