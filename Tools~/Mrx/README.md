# MRX Timeline

Add YAMO MMRP Replayer to a scene object and assign a Playable Director with a saved Timeline Asset. With the Director object selected, GameObject → YAMO → YAMO MMRP Replayer or the button in the MMRP pipeline tab adds or selects the component. In the Registration tab, add Humanoid Animators first, then queue or drop MRX files under each Animator. The importer reconstructs the NatNet source skeleton, saves a Generic Raw FBX, and binds the AnimationClip imported from a Humanoid FBX copy. The target can use different bone names.

The importer discovers the Streamingle Windows x64 reader, MMRP modules and native audio decoder. It checks the YAMO package runtime folder and the project's Streamingle StreamingAssets folder. It discovers CPython 3.14 x64 from the runtime's Python folder, Windows installation records, or the project's MRX validation runtime.

For another PC, provision the matching Streamingle DLLs and modules under the package's Tools~/Mrx/Runtime/Windows-x64 or set YAMO_MRX_RUNTIME to the equivalent folder. The folder needs StreamingleMrxStreaming2.dll, StreamingleVideoEncoder2.dll, MrxModules and Media (the matching native decoder dependencies). Preserve the upstream license notices. Install x64 CPython 3.14 or place its embeddable distribution under Python. YAMO_MRX_PYTHON_HOME can override discovery. The UI does not require executable paths.

Queue one or more MRX files, then register them. Generated Raw FBX, Humanoid FBX and WAV assets are saved in an MMRP folder next to the saved scene that contains the Director. Each file gets a group and motion track named after the file, starting at the playhead. Later take groups for the same Animator start muted, including their motion and audio. Drag the clip or edit its Start in the Timeline Inspector. Edit Position in the clip inspector under Animation Playable Asset to offset the motion. To blend two takes for the same Animator, move their clips onto a single active Animation Track and overlap them. Split or trim the animation clips in Timeline and overlap them to blend. Motion and audio use separate native tracks. Move both clips when realigning a take to preserve the recorded audio offset. Use the master MRX audio popup to mute the other MRX audio tracks. Tracks can be unmuted manually in Timeline.

Decoded intermediates go under Codex. The saved Timeline references the Humanoid FBX clip and optional WAV. The Humanoid importer stores the Raw FBX asset GUID. On Timeline clips, use YAMO MMRP → 원본 FBX 찾기 to locate that source.

Supply the matching MMRP tpose_bind.json in the runtime folder or set YAMO_MRX_BIND_POSE. The importer uses its bind directions and rotations with recorded bone lengths, then reuses the YAMO MMRP humanoid mapping. The runtime binaries, modules and bind data are provisioned separately.

In the Export tab, select the MRX tracks and choose the full Timeline range or enter a start and end in seconds. The batch writes one FBX per selected track using its current Timeline binding. FBX time zero corresponds to the selected range start. Re-register older standalone AnimationClips to use the FBX-backed path. Legacy clips with embedded raw hand data are supported. The exporter reads current Timeline Start, Clip In, duration and blend weights, then samples the Generic Raw FBX for hand targets. The export uses recorded shoulder-relative arm positions and reference-relative wrist rotations, applies a local Z forearm hinge, and projects unreachable positions onto the reachable hinge range. The Console reports the largest remaining hand goal error. The FBX contains only the Bip001 hierarchy, with no mesh or auxiliary bones. Unity writes the FBX through the existing Biped exporter. No 3ds Max process is needed.

For a Max round trip, use Timeline track and clip transform offsets to place the character before export. In MRX 전체, check one or more takes under their bound Animator. Each output spans the source clip from zero at its original speed. It bakes the track transform and, for a split take, the earliest segment's clip transform into the Bip001 world keys. Timeline cuts and blends are exported via Timeline 편집본. Preserve the Bip001 keys through Max and use zero placement offsets when applying the resulting clip back in Unity.
